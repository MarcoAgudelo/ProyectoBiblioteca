Proyecto de Calidad y Pruebas de Software.

Integrantes:
- Marco Antonio Agudelo Corrales

## Estructura

src/
Versión final corregida de la aplicación.

version-inicial/
Código original generado mediante inteligencia artificial antes
de realizar las correcciones.

tests/
Pruebas unitarias implementadas mediante Jest.

Dockerfile
Configuración del contenedor utilizado para ejecutar las pruebas.

docker-compose.yml
Configuración de los servicios de pruebas y SonarQube.

sonar-project.properties
Configuración utilizada para el análisis estático con SonarQube.
